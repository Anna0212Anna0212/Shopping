# 湊單搜尋｜找同時販售多樣商品的賣場

一個專門幫助使用者尋找「同一家賣場同時販售多種指定商品」的線上搜尋工具。

買東西時，常常會遇到想買的商品分散在不同賣場，需要分開下單、支付多次運費的問題。「湊單搜尋」希望解決這個麻煩，讓使用者只需要輸入想購買的商品，就能自動尋找同時販售這些商品的賣場，方便一次購齊、比較價格與評估運費。

**網站：** https://anna0212anna0212.github.io/Shopping/

## 主要功能

- **多商品搜尋**：可同時輸入多項商品，最多支援 6 件商品。
- **同店商品配對**：優先搜尋較冷門的商品，再進一步檢查同一賣場是否也販售其他指定商品，提高尋找符合條件賣場的效率。
- **搜尋數量調整**：可設定搜尋範圍，控制最多檢查的賣場數量。
- **免運門檻篩選**：可設定免運金額，協助尋找適合湊單的賣場。
- **商品數量篩選與排序**：依需求篩選符合條件的結果，方便比較不同賣場。
- **商品關鍵字篩選**：可排除不需要的商品類型，或要求商品標題必須包含指定文字，減少不相關的搜尋結果。
- **隱私與資料保護**：搜尋資料只保存在使用者自己的瀏覽器，不會上傳至網站伺服器。

## 使用情境

例如，想購買「泡椒筍」和「蜂蜜塊」，不必再逐一開啟不同賣場、反覆搜尋商品。使用者可以直接輸入兩項商品，讓系統尋找可能同時販售兩者的店家，再進入商品頁確認價格、規格、庫存及實際運費。

## 設計理念

希望透過自動化搜尋與商品配對，減少購物時反覆查找的時間，讓湊單更有效率，也讓消費者更容易找到符合需求的賣場。

*注意：商品價格、庫存、規格與實際運費仍以蝦皮商品頁及結帳資訊為準，下單前請自行確認。*
